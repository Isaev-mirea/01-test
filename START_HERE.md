# Учебный магазин: запуск и проверки

Python 3.12. Репозиторий: Isaev-mirea/01-test.
Flask обслуживает страницы, SQLite хранит каталог, Waitress запускает сервер.
Корзина отдельная для каждого браузера; данные корзины хранятся в подписанной cookie.
SQLite создаётся в instance/shop.db при первом запуске.
Цены хранятся целым числом копеек, чтобы избежать ошибок float.

## Загрузка в GitHub

Распакуйте архив. Загрузите его содержимое в корень 01-test через
Code → Add file → Upload files. Загружайте файлы и папки, а не ZIP.
Существующие README.md, LICENSE и .github/workflows/runner-check.yml сохраняются:
в этом архиве таких файлов нет.

## PowerShell: локальный запуск из папки проекта

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe build.py
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:8000 . Остановка сервера: Ctrl+C.
Активация venv не нужна. Runner должен работать в другом окне PowerShell.

## Проверка вручную

1. В каталоге пять товаров с названиями, ценами и кнопками.
2. Добавьте масляный фильтр дважды и воздушный фильтр один раз.
3. Откройте корзину: ожидаются количества 2 и 1, общая стоимость 2190 рублей.
4. Очистите корзину: должно появиться «Корзина пуста».
5. Откройте /health: ожидаются status=ok и version=1.0.0.

## Артефакт и дальнейший CI/CD

build.py создаёт dist/shop.zip с приложением, шаблонами, стилями,
тестовыми данными и requirements.txt. База данных и venv в архив не попадают.
Этот архив можно передать между этапами Build и Deploy.
Файлы workflow добавим отдельно после загрузки исходников.

Переменные окружения: PORT (8000), SHOP_DATABASE (путь к SQLite),
SHOP_SECRET_KEY (ключ подписания cookie), BUILD_VERSION (1.0.0).
Без SHOP_SECRET_KEY ключ меняется при перезапуске, корзины сбрасываются.
Задайте постоянный ключ через окружение при настройке развёртывания.
Сервер по умолчанию доступен только на текущем компьютере (127.0.0.1).
Проект учебный: оплата, оформление заказов и авторизация не реализованы.
